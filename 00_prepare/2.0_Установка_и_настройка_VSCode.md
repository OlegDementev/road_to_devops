# Установка и настройка Visual Studio Code (VS Code)

## 🪟 Установка на Windows
Перед установкой VS Code и моего профиля рекомендую установить все необходимые программы и компоненты в систему:
- Python               [ТЫК](https://www.python.org/downloads/)
- Git                  [ТЫК](https://git-scm.com/install/windows).  
- Шрифт JetBrains Mono [ТЫК](https://www.jetbrains.com/lp/mono/).  

Самый простой способ — скачать установщик с официального сайта.  
Скачайте установщик: [code.visualstudio.com. ](https://code.visualstudio.com)  
Установите программу, следуя подсказкам мастера установки.  

На этапе **«Select Additional Tasks»** (Выбор дополнительных задач) рекомендуется отметить все галочки. Особенно важны:
+ «Add "Open with Code" action...»: Добавляет удобный пункт в контекстное меню проводника.
+ «Add to PATH»: Позволяет запускать VS Code из командной строки командой code.

## 💼 Портативная версия
Если вы хотите запускать VS Code с USB-флешки, не устанавливая его на компьютер, скачайте ZIP-архив для Windows. Распакуйте его в любую папку и создайте рядом с исполняемым файлом папку с именем data. После этого все настройки и расширения будут сохраняться в этой папке, а не в системных директориях.

## ✅ После установки
Чтобы убедиться, что всё прошло успешно, откройте терминал (или командную строку) и введите команду:

```bash
code --version
```
Если установка прошла правильно и вы добавили VS Code в **PATH**, команда выведет номер версии редактора.  
Теперь VS Code готов к работе. Вы можете начать настраивать его под себя: устанавливать расширения для нужных языков программирования, менять тему оформления и шрифты.

Чтобы понять, как работать в **VS Code** посмотрите пару уроков на [YouTube](https://www.youtube.com/watch?v=dQw4w9WgXcQ)

## 👾 Установка профиля в VS Code как у меня
Профиль в VS Code — это набор настроек, горячих клавиш, расширений и состояния интерфейса. Установить готовый профиль можно так:

### Импорт из файла `.code-profile`
1. Откройте VS Code.
2. Нажмите на **шестерёнку** (Manage) в левом нижнем углу.
3. Выберите **Profiles** → **Import Profile…**.
4. Укажите файл профиля (обычно имеет расширение `.code-profile`).
5. Введите имя профиля.
6. Отметьте, что импортировать: **Settings**, **Keybindings**, **Extensions**, **UI State**, **Snippets**, **Tasks**.
7. Нажмите **Create Profile**. VS Code предложит установить расширения из профиля — подтвердите.
8. Переключиться на профиль можно через то же меню **Profiles**, сделайте это. **Импортированный профиль сам не активируется.**

## 📝 Что и для чего установлено в моём профиле
Файл находится в этом репозитории по пути `00_prepare\Profile_tolkonemen9i.code-profile`.  

В моём профиле настроена среда для Python, SQL, работы с Git, Markdown и терминала.  

### 🎨 Внешний вид и шрифты
- **Тема оформления**: `Dark Modern` (встроенная).
- **Иконочная тема**: `symbols` — расширение **Symbols** (иконки для файлов).
- **Тема иконок продукта**: `fluent-icons` — расширение **Fluent Icons**.
- **Шрифт**: `JetBrains Mono` для редактора и терминала. Требуется отдельная установка шрифта в систему.  
- **Настройки редактора**: размер шрифта 16, межстрочный интервал 1.5, отключён минимап, плавная прокрутка, плавная анимация курсора, отображение всех пробельных символов, вертикальная линейка на 99 символов.
- **Кастомизация семантики Python**: для тёмной темы `Default Dark Modern` заданы цвета для параметров `self` и `cls` (`#E6C58F`).

### 🖥️ Терминал
- **Профили Windows**: PowerShell, Command Prompt, Git Bash, Windows PowerShell.
- **Профиль по умолчанию**: `Git Bash` (требуется установленный Git for Windows).
- **Настройки курсора**: стиль `line`, мигание, неактивный курсор — блок.
- **Цвета терминала**: кастомизированы под тёмную схему (похоже на Tomorrow Night).
- **Плавная прокрутка**, отключено предупреждение о многострочной вставке.

### 🐍 Python
- **Языковой сервер**: `Pylance` — расширение **Pylance**.
- **Форматтер по умолчанию**: `ms-python.black-formatter` — расширение **Black Formatter**.
- **Автодополнение скобок функций**: включено.
- **Инлей-хинты** для типов переменных и возвращаемых значений: отключены.
- **Режим проверки типов**: `standard`.
- **Создание окружения**: отключено (`python.createEnvironment.trigger: off`).

### 🗄️ SQL
- **Форматтер для SQL**: `inferrinizzard.prettier-sql-vscode` — расширение **Prettier SQL**.
- **Диалект SQL**: `sqlite`.
- **Ассоциация файлов**: `.xlsx` открываются встроенным редактором.

### 📝 Git
- **Автофетч**: включён.
- **Подтверждение синхронизации**: отключено.
- **Открытие репозитория в родительских папках**: запрещено.
- **Подтверждение удаления и drag-and-drop** в проводнике: отключены.

### 📖 Markdown
- **Markdown Preview Github Styles**: расширение для предпросмотра Markdown в стиле GitHub.
- **Тема предпросмотра**: `dark`, `dark_dimmed`.

### 🔤 Проверка орфографии
- **Code Spell Checker** (`cSpell`): включены языки `en` и `ru`.
- Добавлен большой список пользовательских слов (технические термины, имена, команды).

### 📊 CSV
- **Rainbow CSV**: автоматическое определение разделителей `TAB`, `,`, `;`.

### ⌨️ Прочие расширения и настройки
- **TabOut**: `tabout.disableByDefault: false` — позволяет выходить из скобок и кавычек по Tab.
- **Файловая вложенность** (`explorer.fileNesting.patterns`): настроены шаблоны для TypeScript, JavaScript, JSON, SQLite и др.
- **Автосохранение**: `afterDelay`.
- **Форматирование при сохранении**: включено.
- **Отключён предпросмотр редакторов** (`workbench.editor.enablePreview: false`).
- **Стартовый редактор**: пустой (`none`).
