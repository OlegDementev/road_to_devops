## Магия текстовой обработки: потоки, конвейеры и фильтры <a id="t_6.0"></a>
### Философия Unix <a id="t_6.1"></a>
В Unix всё есть файл. Конфигурации — текстовые файлы. Логи — текстовые файлы. Вывод почти любой команды — текст. Даже устройства вроде жёстких дисков или клавиатуры представлены в виде файлов в каталоге `/dev`.

Программы должны общаться между собой через текст. Каждая утилита в Linux решает одну узкую задачу и делает это хорошо.  

Это и есть философия `Unix`, сформулированная ещё в 1970-х годах:

> Пиши программы, которые делают одну вещь, но делают её хорошо.  
> Пиши программы так, чтобы они могли работать вместе.  
> Пиши программы так, чтобы они обрабатывали текстовые потоки, потому что это универсальный интерфейс.  

### Конвейер (pipe) (`|`) <a id="t_6.2"></a>
Он берёт `stdout` левой команды и передаёт его в `stdin` правой. `stderr` идёт мимо, прямо на терминал. Pipe нужен тогда, когда данные рождаются на лету — из вывода другой команды, из потока, из нескольких источников.

Примеры:
```bash
ls -l | less                # длинный вывод листаем постранично
cat file.txt | wc -l        # считаем строки в файле
ps aux | grep bash          # ищем процессы с "bash"
```

### Поиск по тексту: grep [global regular expression print] <a id="t_6.4"></a>
Команда `grep` ищет строки в текстовых файлах или стандартном вводе, соответствующие заданному шаблону (регулярному выражению), и выводит их.  
`egrep` — устаревший синоним `grep -E`.  
`fgrep` — устаревший синоним `grep -F`. 

```bash
grep [OPTION]... PATTERN [FILE]...

[OPTION]:
-i               — игнорировать регистр
-v               — инвертировать совпадение (выводить строки, не содержащие шаблон)
-r, -R           — рекурсивный поиск в директориях
-l               — выводить только имена файлов с совпадениями
-n               — показывать номера строк
-c               — выводить только количество совпадающих строк
-E               — использовать расширенные регулярные выражения
-F               — интерпретировать шаблон как фиксированную строку
-w               — искать только целые слова
-A N             — показать N строк после совпадения
-B N             — показать N строк перед совпадением
-C N             — показать N строк контекста до и после
--color=auto     — Подсветить совпадения

[EXAMPLE]:
grep "error" log.txt              # найти error в log.txt
grep "error" file1.txt file2.txt  # по нескольким файлам
grep -i "warning" log.txt         # warning без учёта регистра
grep -r "TODO" ./src/             # рекурсивно найти TODO в src
grep -l "password" *.conf         # имена файлов с password
grep -n "main" script.py          # строки с main с номерами
grep -c "fail" log.txt            # сколько раз встречается fail
grep -v "debug" app.log           # все строки кроме debug
grep -A 2 "Error" log.txt         # Error и 2 строки после

# В базовом режиме +, ?, |, (), {} работают только с экранированием через \.  
# Флаг -E включает расширенный режим — там они работают как есть.
grep -E "color|colour" file.txt   # расширенное регулярное выражение (или)
grep -E "error|warn|critical" file.log    # ИЛИ
grep -E "err(or)?s" file.log              # or опционально
grep -E "[0-9]{3}" file.log               # ровно 3 цифры
grep -E "^err+" file.log                  # одно или больше r
```

### Колонки и поля: cut и awk [Aho, Weinberger, Kernighan] <a id="t_6.5"></a>
Команда `cut` извлекает заданные части строк из текстовых файлов или стандартного ввода, используя байты, символы или поля, разделённые разделителем.  
**Ограничение** `cut`: разделитель — это один символ. Если в файле несколько пробелов подряд, `cut -d' '` создаст пустые поля.  
Здесь начинается зона `awk`.

```bash
cut [OPTION]... [FILE]...

[OPTION]:
-b LIST          — вывести байты из указанных позиций (например, -b 1-5, -b 3)
-c LIST          — вывести символы из указанных позиций (аналогично -b, но с учётом многобайтовой кодировки)
-f LIST          — вывести поля (поля разделяются TAB по умолчанию)
-d DELIM         — задать разделитель для полей (вместо TAB)
-s               — не выводить строки, которые не содержат разделитель
--complement     — вывести всё, кроме указанных байтов/символов/полей
--output-delimiter=DELIM — задать разделитель в выводе для полей

[EXAMPLE]:
cut -d: -f1 /etc/passwd                 # поле 1, разделитель ":" (вывести логины из /etc/passwd)
cut -d' ' -f1,3 file.log                # поля 1 и 3
cut -d' ' -f1-3 file.log                # поля с 1 по 3

cut -c1-10 file.txt                     # первые 10 символов каждой строки
cut -b3-5 file.txt                      # байты с 3 по 5
cut -f2,3 -d',' data.csv                # 2-е и 3-е поля из CSV
cut -s -f1 -d' ' list.txt               # первое поле, только строки с пробелом
cut -f1-3 --complement -d: /etc/passwd  # все поля кроме 1-3
```

Команда `awk` — это язык обработки текста и утилита для поиска, фильтрации и преобразования данных. Она читает входной поток построчно, разбивает каждую строку на поля и выполняет заданные действия по шаблонам.  

```bash
awk [OPTION]... 'PATTERN {ACTION}' [FILE]...
awk -f SCRIPTFILE [FILE]...

[OPTION]:
-F FS            — задать разделитель полей (например, -F: или -F,)
-v VAR=VALUE     — присвоить переменную до выполнения программы
-f FILE          — читать программу awk из указанного файла

[EXAMPLE]:
awk '{print $1}' file.txt                    # вывести первое поле каждой строки
awk -F: '{print $1}' /etc/passwd             # логины из /etc/passwd (разделитель :)
awk '{print $0}' file.txt                    # вывести строку целиком ($0)
awk '$3 > 100 {print $1, $3}' file.txt       # строки, где 3-е поле больше 100
awk -F, '{sum+=$2} END{print sum}' data.csv  # сумма значений 2-го поля
awk -v x=10 '{print $1*x}' file.txt          # умножить 1-е поле на 10
awk -f script.awk file.txt                   # выполнить программу из файла
```

По умолчанию `awk` режет строку по любым пробельным символам (пробелы, табы) и схлопывает повторяющиеся разделители. Это главное отличие от `cut`.  

```bash
Строка:  root  1000  /bin/bash
$1 = root
$2 = 1000
$3 = /bin/bash
$NF = /bin/bash
```
Команда `awk` умеет фильтровать, как `grep`, но по полям.  
Синтаксис: `awk` `'условие {действие}' файл`.  
Если **условие** опущено — действие для всех строк.  
Если **действие** опущено — печатается вся строка.   

```bash
awk -F: '$3 > 1000 {print $1}' /etc/passwd       # пользователи с UID > 1000
awk '$2 == "ERROR" {print $0}' file.log          # точное совпадение
awk '/error/ {print $1}' file.log                # /шаблон/ как grep
```

Команда`cut` быстрее и проще, `awk` мощнее.

```bash
cut -d: -f1 /etc/passwd                        # список пользователей
awk -F: '{print $1, $7}' /etc/passwd           # пользователь + его оболочка
awk '$9 == 404 {print $1}' access.log          # IP для всех 404
awk -F: '$3 >= 1000 {print $1}' /etc/passwd    # обычные (не системные) пользователи
```

### Сортировка и подсчёт: sort и uniq <a id="t_6.6"></a>
Команда `sort` сортирует строки текстовых файлов или стандартного ввода и выводит результат в стандартный вывод. Поддерживает сортировку по алфавиту, числам, полям и с изменением порядка.

```bash
sort [OPTION]... [FILE]...

[OPTION]:
-n, --numeric-sort       — сортировать как числа
-r, --reverse            — обратный порядок сортировки
-u, --unique             — выводить только уникальные строки (после сортировки)
-f, --ignore-case        — игнорировать регистр
-k N[,M], --key=N[,M]    — сортировать по полю N (или диапазону полей N–M)
-t DELIM, --field-separator=DELIM — задать разделитель полей
-o FILE, --output=FILE   — записать результат в FILE вместо stdout
-h, --human-numeric-sort — сортировать с учётом суффиксов (K, M, G)
-M, --month-sort         — сортировать по названию месяца (JAN, FEB...)
-R, --random-sort        — случайный порядок (с возможностью -u)

[EXAMPLE]:
sort file.txt                     # сортировка строк по алфавиту
sort -n numbers.txt               # сортировка чисел
sort -r file.txt                  # обратный порядок
sort -u file.txt                  # уникальные строки
sort -k2 file.txt                 # по второму полю
sort -t: -k3 -n /etc/passwd       # по 3-му полю, разделитель :, как числа
sort -h sizes.txt                 # сортировка размеров: 1K, 500K, 2M, 1G
sort -o sorted.txt input.txt      # записать результат в файл
```

Команда `uniq` удаляет или подсчитывает повторяющиеся строки во входном потоке.  
Важно: **она сравнивает только соседние строки**, поэтому обычно используется после `sort`.

```bash
uniq [OPTION]... [INPUT [OUTPUT]]

[OPTION]:
-c, --count           — показать количество повторений перед каждой строкой
-d, --repeated        — выводить только повторяющиеся строки
-u, --unique          — выводить только уникальные строки
-i, --ignore-case     — игнорировать регистр при сравнении
-f N, --skip-fields=N — пропустить первые N полей перед сравнением
-s N, --skip-chars=N  — пропустить первые N символов перед сравнением
-w N, --check-chars=N — сравнивать только первые N символов

[EXAMPLE]:
uniq file.txt                 # удалить соседние дубликаты
sort file.txt | uniq          # удалить все дубликаты (после сортировки)
sort file.txt | uniq -c       # подсчитать количество повторений
sort file.txt | uniq -d       # только строки, которые повторяются
sort file.txt | uniq -u       # только уникальные строки
uniq -i file.txt              # игнорировать регистр
uniq -f 1 file.txt            # пропустить первое поле при сравнении
```

Сценарии использования
```bash
# Топ-10 самых частых ошибок в логе
grep "ERROR" /var/log/syslog | sort | uniq -c | sort -rn | head

# Сколько раз каждый IP заходил на сервер
cut -d' ' -f1 access.log | sort | uniq -c | sort -rn

# Уникальные оболочки в системе
cut -d: -f7 /etc/passwd | sort -u

# Список пользователей по UID
awk -F: '{print $3, $1}' /etc/passwd | sort -n
```

### Замена и трансформация: tr, expand, unexpand <a id="t_6.7"></a>
Команда `tr` преобразует, удаляет или заменяет символы из стандартного ввода, выводя результат в стандартный вывод. Работает только с `stdin` — файл как аргумент не принимает, поэтому всегда через `pipe` или `<`. Работает путём сопоставления наборов символов.  
**Важно**: `tr` не понимает регулярки и не умеет заменять целые слова. Только посимвольная замена. Для сложных замен — `sed`, но о нём в другой главе.

```bash
tr [OPTION]... SET1 [SET2]

[OPTION]:
-d               — удалить символы из SET1 (SET2 не используется)
-s               — сжать повторяющиеся символы из SET1 в один
-c, -C           — использовать дополнение к SET1 (все символы, кроме указанных)
-t               — обрезать SET1 до длины SET2

[EXAMPLE]:
echo "hello" | tr 'a-z' 'A-Z'    # преобразовать в верхний регистр (HELLO)
echo "HELLO" | tr 'A-Z' 'a-z'    # в нижний регистр (hello)
echo "hello  world" | tr -s ' '  # сжать пробелы (hello world)
echo "abc123" | tr -d '0-9'      # удалить все цифры (abc)
echo "hello" | tr 'l' 'p'        # заменить все l на p (heppo)
echo "hello" | tr -c 'l' '*'     # заменить все кроме l на * (*ll*)

# сжимаем пробелы, заменяем их на переносы строк (каждое слово — отдельная строка), сортируем, считаем, выводим топ.
cat text.txt | tr -s ' ' '\n' | sort | uniq -c | sort -rn | head
```

Команда `expand` преобразует символы табуляции во входном потоке в соответствующее количество пробелов и выводит результат в стандартный вывод.

```bash
expand [OPTION]... [FILE]...

[OPTION]:
-t N, --tabs=N       — задать ширину табуляции (по умолчанию 8)
-t LIST, --tabs=LIST — задать список позиций табуляции (например, 4,8,12)
-i, --initial        — преобразовывать только начальные табуляции (отступы)
-a, --all            — преобразовывать все табуляции (по умолчанию)

[EXAMPLE]:
expand file.txt                # заменить все табуляции на пробелы (ширина 8)
expand -t 4 file.txt           # ширина табуляции 4 пробела
expand -t 4,8,12 file.txt      # табуляции на позициях 4, 8, 12
expand -i file.txt             # только начальные табуляции
cat file.txt | expand -t 2     # из stdin, ширина 2
```

Команда `unexpand` преобразует пробелы во входном потоке в символы табуляции и выводит результат в стандартный вывод. По умолчанию заменяет только ведущие пробелы (в начале строки)

```bash
unexpand [OPTION]... [FILE]...

[OPTION]:
-a, --all        — преобразовывать все пробелы, а не только начальные
-t N, --tabs=N   — задать ширину табуляции (по умолчанию 8)
--first-only     — преобразовывать только начальные пробелы (по умолчанию)

[EXAMPLE]:
unexpand file.txt              # заменить начальные пробелы на табуляции (ширина 8)
unexpand -a file.txt           # заменить все пробелы на табуляции
unexpand -t 4 file.txt         # ширина табуляции 4
unexpand -t 4,8,12 file.txt    # табуляции на позициях 4, 8, 12
cat file.txt | unexpand -a     # из stdin, все пробелы
```

### Объединение и разделение: paste, join, split, tee <a id="t_6.8"></a>
Команда `paste` объединяет строки из нескольких файлов горизонтально, вставляя между ними разделитель (по умолчанию — табуляция). Также может объединять все строки одного файла в одну с помощью `-s`.

```bash
paste [OPTION]... [FILE]...

[OPTION]:
-d LIST, --delimiters=LIST — использовать указанные разделители вместо TAB (можно несколько, по кругу)
-s, --serial               — объединять все строки одного файла последовательно в одну строку
-z, --zero-terminated      — строки разделяются нулевым байтом (для xargs -0)

[EXAMPLE]:
paste file1.txt file2.txt          # объединить строки двух файлов через TAB
paste -d, file1.txt file2.txt      # разделитель — запятая
paste -d' : ' file1.txt file2.txt  # разделители по кругу: пробел, двоеточие, пробел...
paste -s file.txt                  # все строки файла в одну строку через TAB
paste -s -d, file.txt              # все строки файла в одну строку через запятую
paste file1.txt - file2.txt        # смешать файл и stdin


# Пример
file1:  a       file2:  1       paste:  a    1
        b               2               b    2
        c               3               c    3
```

Команда `join` объединяет строки двух файлов по общему полю (ключу), как `JOIN в SQL`. Файлы должны быть отсортированы по этому полю. Выводит результат в стандартный вывод.  
По умолчанию ключом считается первое поле, разделитель — пробельные символы.

```bash
join [OPTION]... FILE1 FILE2

[OPTION]:
-1 N             — использовать N-е поле первого файла как ключ
-2 N             — использовать N-е поле второго файла как ключ
-t CHAR          — задать разделитель полей (по умолчанию пробел/табуляция)
-a N             — выводить также строки без совпадений из файла N (1 или 2)
-v N             — выводить только строки без совпадений из файла N
-i, --ignore-case — игнорировать регистр при сравнении ключей
-o FORMAT        — задать формат вывода (например, 1.1,2.2)
-e STRING        — заменять отсутствующие поля указанной строкой
--header         — считать первую строку заголовком и выводить её
--check-order    — проверять, что файлы отсортированы по ключу
--nocheck-order  — не проверять порядок сортировки (по умолчанию)

[EXAMPLE]:
join file1.txt file2.txt              # объединить по первому полю
join -1 2 -2 3 file1.txt file2.txt    # ключ: 2-е поле file1 и 3-е поле file2
join -t, file1.csv file2.csv          # разделитель — запятая
join -a1 file1.txt file2.txt          # показать все строки file1, даже без пары
join -v2 file1.txt file2.txt          # только строки file2 без совпадений
join -o 1.1,2.2 file1.txt file2.txt   # вывести 1-е поле file1 и 2-е поле file2
join -i file1.txt file2.txt           # игнорировать регистр ключей
join --header file1.txt file2.txt     # первая строка — заголовок

# Пример
users.txt:      uid.txt:
alice 1001      1001 /bin/bash
bob   1002      1002 /bin/zsh
```

Команда `split` разбивает один большой файл на несколько меньших частей по строкам, байтам или на заданное количество файлов. Имена частей формируются из префикса (по умолчанию x) и суффикса (aa, ab, ... или 00, 01, ...).

```bash
split [OPTION]... [FILE [PREFIX]]

[OPTION]:
-l N, --lines=N              — разбить по N строк (по умолчанию 1000)
-b SIZE, --bytes=SIZE        — разбить по SIZE байт (можно K, M, G)
-n N, --number=N             — разбить на N равных частей
-d, --numeric-suffixes       — использовать цифровые суффиксы (00, 01...)
-a N, --suffix-length=N      — длина суффикса (по умолчанию 2)
--additional-suffix=SUFFIX   — добавить суффикс к именам файлов
-e, --elide-empty-files      — не создавать пустые файлы

[EXAMPLE]:
split file.txt                 # разбить file.txt на части по 1000 строк (xa, xb, ...)
split -l 500 file.txt part_    # по 500 строк, префикс part_ (part_aa, part_ab...)
split -b 10M bigfile.bin       # разбить по 10 МБ
split -n 5 data.txt            # разбить на 5 частей
split -d -a 3 file.txt         # цифровые суффиксы длиной 3 (x000, x001...)
split -e -l 100 file.txt       # не создавать пустые файлы
```

Команда `tee` читает данные из стандартного ввода и одновременно записывает их в стандартный вывод и в один или несколько файлов.

```bash
tee [OPTION]... [FILE]...

[OPTION]:
-a, --append     — дописывать в конец файлов, а не перезаписывать
-i, --ignore-interrupts — игнорировать сигналы прерывания (SIGINT)

[EXAMPLE]:
echo "hello" | tee file.txt              # записать "hello" в файл и показать на экране
ls -la | tee listing.txt                 # сохранить вывод ls в файл и вывести на экран
echo "log" | tee -a log.txt              # дописать "log" в конец log.txt
command | tee file1.txt file2.txt        # записать в два файла одновременно

# Запустить долгий процесс и сохранить его вывод
long_command | tee build.log

# Сохранить всё, но сразу отфильтровать на экране
command | tee full.log | grep "ERROR"

# Писать в защищённый файл через sudo
echo "text" | sudo tee /etc/some.conf > /dev/null
```

### Собираем всё вместе <a id="t_6.9"></a>
Рассмотрим задачу для примера.  
Есть лог-файл `app.log`. Нужно понять, какие ошибки встречаются чаще всего.  

```bash
2024-01-15 10:23:11 ERROR Failed to connect to db
2024-01-15 10:23:12 INFO Retry connection
2024-01-15 10:23:15 ERROR Failed to connect to db
2024-01-15 10:24:01 ERROR Timeout on request
2024-01-15 10:24:05 ERROR Failed to connect to db
2024-01-15 10:25:33 INFO Connection restored
```

Решаем одной командой
```bash
cat app.log | grep "ERROR" | cut -d' ' -f4- | sort | uniq -c | sort -rn

# Вывод
3 Failed to connect to db
1 Timeout on request
```
Разбор решения по шагам

```bash
cat app.log
# Читаем файл, вывод уходит в pipe.

grep "ERROR"
# Оставляем только строки с ERROR. Осталось:
2024-01-15 10:23:11 ERROR Failed to connect to db
2024-01-15 10:23:15 ERROR Failed to connect to db
2024-01-15 10:24:01 ERROR Timeout on request
2024-01-15 10:24:05 ERROR Failed to connect to db

cut -d' ' -f4-
# Режем по пробелу, берём поля с 4-го до конца.  
# Первые три поля (дата, время, уровень) отбрасываем — остаётся только текст ошибки.
# Флаг -f4- означает «с 4-го поля до последнего». Если нап исать -f4, возьмётся только слово Failed.
Failed to connect to db
Failed to connect to db
Timeout on request
Failed to connect to db

sort
# Сортируем — нужно для uniq
Failed to connect to db
Failed to connect to db
Failed to connect to db
Timeout on request

uniq -c
# Считаем повторы
3 Failed to connect to db
1 Timeout on request

sort -rn
# Сортируем по числу повторов, от большего к меньшему. -r — обратный порядок, -n — числовая сортировка (без неё 10 окажется раньше 2).
3 Failed to connect to db
1 Timeout on request

# Добавим head, чтобы получить только топ-5
cat app.log | grep "ERROR" | cut -d' ' -f4- | sort | uniq -c | sort -rn | head -n 5

# Альтернатива на awk
awk '/ERROR/ {print $4, $5, $6, $7}' app.log | sort | uniq -c | sort -rn
```
Важные моменты:
+ Конвейер читается слева направо. Каждая команда берёт результат предыдущей и что-то с ним делает.  
+ Каждая команда делает одно.  
+ Порядок имеет значение.  
+ sort | uniq -c | sort -rn — такая связка встречается постоянно, запомни.
+ Всё можно отладить через `tee`.

```bash
cat app.log | grep "ERROR" | tee step1.txt | cut -d' ' -f4- | tee step2.txt | sort | uniq -c
```

### Реальные сценарии использования конвейеров <a id="t_6.10"></a>

Задача: найти 5 самых частых сообщений об ошибках за сегодня.

```bash
grep "$(date +%Y-%m-%d)" /var/log/syslog | grep -i "error" | cut -d' ' -f6- | sort | uniq -c | sort -rn | head -n 5

# Оставляем только сегодняшние записи. $(...) подставляет результат команды date в строку
grep "$(date +%Y-%m-%d)" 
# Фильтр по ошибкам, без учёта регистра
grep -i "error"
# Отбрасываем дату, время, хост, процесс — оставляем только текст
cut -d' ' -f6- — 
# Считаем и выводим топ-5
sort | uniq -c | sort -rn | head -n 5 — 
```

Задача: вывести всех обычных пользователей (UID ≥ 1000) и их оболочки, отсортировав по имени.

```bash
awk -F: '$3 >= 1000 && $3 < 65534 {print $1, $7}' /etc/passwd | sort

# Разделитель :
-F:
# UID от 1000 до 65533. Диапазон 65534 (nobody) исключаем
$3 >= 1000 && $3 < 65534
# Имя и оболочка
{print $1, $7}
# Сортировка по алфавиту
sort
```

Задача: посчитать, сколько раз каждый IP обращался к серверу.

grep "$(date +%d/%b/%Y)" /var/log/nginx/access.log | awk '{print $1}' | sort | uniq -c | sort -rn | head
