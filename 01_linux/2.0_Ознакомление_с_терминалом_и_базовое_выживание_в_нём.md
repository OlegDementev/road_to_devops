## Ознакомление с терминалом и базовое выживание в нём <a id="t_2.0"></a>
### Немного философии linux <a id="t_2.1"></a>
#### Всё есть файл <a id="t_2.1.1"></a>
Диски, процессы, устройства и даже настройки ядра представлены как файлы. Единый интерфейс для работы с разнородными объектами через знакомые системные вызовы (open, read, write, ioctl).

#### Маленькие программы, делающие одну вещь хорошо <a id="t_2.1.2"></a>
Их соединяют в цепочки, передавая текст от одной к другой. Ключевая сила не в отдельных утилитах, а в их соединении через пайпы (|). Каждая программа читает `stdin`, пишет в `stdout`, и это позволяет строить цепочки.

```bash
# Классический пример (поиск частоты запросов в логе):
cat access.log | awk '{print $1}' | sort | uniq -c | sort -nr | head -10
```

#### Текст — универсальный интерфейс <a id="t_2.1.3"></a>
Вывод любой команды можно отфильтровать, посчитать, отсортировать и передать дальше.  
Любой вывод — это строки, а строки можно обработать сотней способов: `grep, cut, sort, uniq, wc, head/tail, sed, awk`.

```bash
Пример — мониторинг логов в реальном времени:
tail -f /var/log/syslog | grep -i error | while read line; do echo "ALERT: $line"; done
```

#### Конфигурация — это текстовые файлы <a id="t_2.1.4"></a>
Почти всё в системе настраивается правкой файлов в `/etc`. Это значит, что настройку можно сохранить, скопировать на другой сервер и положить в систему контроля версий. Это даёт воспроизводимость и автоматизацию. `/etc` — глобальные настройки, `~/.config` — пользовательские.

### Первый запуск терминала Linux <a id="t_2.2"></a>
При запуске терминала первым делом встретиться приглашение к вводу команды - `promtf`.  

```bash
# обычный_пользователь
alice@server:~$

# супер_пользователь
root@server:~#

"root", "alice":   - имя пользователя
"server"  - имя хоста, то есть машины
"~"       - текущая директория
"#"       - ты работаешь как суперпользователь root
"$"       - ты работает как обычный пользователь
```
Основы навигации в терминале состоят из понимания спецсимволов, горячих клавиш и базовых команд навигации (зубрить это не надо).  

```bash
# Специальные символы
`.`  текущая директория  
`..` директория на уровень выше  
`~`  домашняя директория  
`*`  любое кол-во символов  
`?`  ровно один символ  

# Сочетания клавиш для терминала
`Tab`    Автодополнение команды или пути; два нажатия показывают варианты  
`↑ / ↓`  Перемещение по истории команд (1000 шт)  
`reset`  Полностью восстанавливает корректное отображение.

# Навигация по строке ввода
Ctrl + A           Переместить курсор в начало строки
Ctrl + E           Переместить курсор в конец строки
Ctrl + F           Переместить курсор на один символ вперёд
Ctrl + B           Переместить курсор на один символ назад
Ctrl + XX          Переключить позицию курсора между началом строки и текущей позицией
Ctrl + ] + x       Переместить курсор вперёд к следующему вхождению символа x
Alt + F / Esc + F  Переместить курсор на одно слово вперёд
Alt + B / Esc + B  Переместить курсор на одно слово назад
Alt + Ctrl + ] + x Переместить курсор к предыдущему вхождению символа x

# Управление терминалом и процессами
Ctrl + L  Очистить экран терминала (аналогично команде clear)
Ctrl + S  Приостановить вывод команды на экран
Ctrl + Q  Возобновить вывод, приостановленный Ctrl+S
Ctrl + Z  Приостановить выполнение текущей команды и отправить её в фон
Ctrl + C  Отправить сигнал SIGINT и завершить выполняющуюся команду
Ctrl + D  Закрыть текущий терминал (отправить EOF)

# Работа с историей команд
Ctrl + R      Инкрементный обратный поиск по истории
Alt + P       Неинкрементный обратный поиск по истории
Ctrl + J      Завершить поиск по истории, оставив текущую команду
Ctrl + G      Выйти из режима поиска по истории
Ctrl + _      Отменить последнее изменение в строке
Ctrl + P / ↑  Перейти к предыдущей команде в истории
Ctrl + N / ↓  Перейти к следующей команде в истории
Ctrl + S      Перейти к следующей (более старой) команде в результатах поиска
Ctrl + O      Выполнить найденную команду (через Ctrl+R/S) и продолжить поиск

# Специальные команды истории (вводятся в строке)
!!            Выполнить последнюю команду
!*            Выполнить предыдущую команду, кроме первого слова
!*:p          Показать, что подставит команда !* (без выполнения)
!x            Выполнить последнюю команду из истории, начинающуюся с x
!x:p          Показать команду, начинающуюся с x, и добавить её в историю
!$ / Alt + .  Подставить последний аргумент предыдущей команды
!$:p          Показать, что подставит !$ (без выполнения)
!^            Подставить первый аргумент предыдущей команды
^123^abc      Заменить в предыдущей команде 123 на abc и выполнить
!n            Выполнить команду под номером n из истории
!n:p          Показать команду под номером n (без выполнения)
!n:m          Повторить аргументы с номера n по m из последней команды
!n:$          Повторить аргументы от n до последнего из последней команды
!fi           Выполнить последнюю команду из истории, начинающуюся с fi

# Редактирование строки ввода
Ctrl + U           Удалить от курсора до начала строки
Ctrl + K           Удалить от курсора до конца строки
Ctrl + W           Удалить слово/аргумент перед курсором
Ctrl + D           Удалить символ под курсором (или закрыть терминал)
Ctrl + H           Удалить символ перед курсором (как Backspace)
Alt + D            Удалить от курсора до конца слова
Alt + Backspace    Удалить от курсора до начала слова
Alt + . / Esc + .  Вставить последний аргумент предыдущей команды
Alt + <            Перейти к первой команде в истории
Alt + >            Перейти к последней команде в истории
Esc + T            Поменять местами два последних слова перед курсором
Alt + T            Поменять местами текущее и предыдущее слово

# Автодополнение и информация
Tab                Автодополнение команды или имени файла/каталога
`~ затем Tab Tab`  Показать список всех пользователей системы
Ctrl + I           Аналогично Tab (автодополнение)
Alt + ?            Показать список файлов и каталогов в текущем пути (справка)
Alt + *            Вставить имена всех файлов и каталогов в текущем пути как аргументы
```

### Информационные команды терминала <a id="t_2.3"></a>
Узнать какой это дистрибутив и его версию можно так: `cat /etc/os-release`.  
Далее будут рассмотрены базовые информационные команды:

```bash
history  - просмотр истории команд
whoami   - показать текущего пользователя
w        - показать кто залогинен и что делает
who      - показать список пользователей и что они делают
whereis  - показать исполняемый файл, исходники и man-страницы
which    - показать полный путь к исполняемому файлу указанной команды (ищет в PATH)
last     - показать список последних успешных входов пользователей
id       - показать информацию о пользователе
hostname - показать или изменить имя хоста системы
date     - показать или изменить дату и время в системе
uptime   - показать длительность работы системы и нагрузку
echo     - показать строку текста, который был передан в неё
```

#### history [history] <a id="t_2.3.1"></a>
Команда для просмотр, повторного выполнения и управления списком ранее введённых команд.

```bash
history [-c] [-d смещение] [n]
 
[OPTION]:
-c         — очистить историю текущей сессии
-d N       — удалить запись с номером N
-a         — дописать новые команды сессии в файл истории (~/.bash_history)
-r         — прочитать файл истории и добавить в текущий список
-w         — записать текущий список в файл истории
-n         — показать последние n команд

[EXAMPLE]:
history          # вывести всю историю с номерами (максимальная глубина - 1000 команд)
history 5        # последние 5 команд
history -c       # очистить историю
history -d 42    # удалить команду №42
!42              # выполнить команду №42
!!               # повторить последнюю команду
!grep            # выполнить последнюю команду, начинающуюся с 'grep'
```

#### whoami [print effective user name] <a id="t_2.3.2"></a>
Показать имя текущего пользователя

```bash
whoami
```

#### w [show who is logged on and what they are doing] <a id="t_2.3.3"></a>
Показать, кто залогинен и что делает. Выводит список пользователей, их терминалы, время входа, idle time, использование CPU, и текущую команду.

```bash
w [OPTION] [USERS]

[OPTION]:

w username — только для конкретного пользователя
-h — не показывать строку заголовка
-s — краткий формат (без времени входа и CPU)
-f — не показывать поле FROM (удалённый хост)
-u — показать время безотказной работы и процессы только текущего пользователя (по умолчанию)
-i — показывать IP-адреса вместо хостов
```

#### who [show who is logged on] <a id="t_2.3.4"></a>
Выводит список пользователей, их терминалы, время входа и удалённый хост (если есть).

```bash
who [OPTION]... [ FILE | ARG1 ARG2 ]

[OPTION]:

-b — время последней загрузки (boot)
-q — только имена и количество (quick)
-H — показать строку заголовка
-u — показать idle time и PID процесса
-r — текущий уровень запуска (runlevel)
```

#### whereis [locate binary, source, and manual page files] <a id="t_2.3.5"></a>
Найти исполняемый файл, исходники и man-страницы

```bash
whereis [options] [-BMS directory... -f] name...

[OPTION]:

-b — искать только бинарные файлы
-m — искать только man-страницы
-s — искать только исходники
-u — показать файлы, у которых нет каждого типа (необычные)
-B — задать список папок для поиска бинарников (-B /usr/bin -f ls)
-M — задать список папок для man-страниц
-S — задать список папок для исходников
```

#### which [locate a command]<a id="t_2.3.6"></a>
Команда находит и выводит полный путь к исполняемому файлу указанной команды, ища в каталогах, перечисленных в переменной окружения `PATH`.

```bash
which [OPTION]... COMMAND...

[OPTION]:
-a               — вывести все найденные пути (не только первый)
-s               — не выводить ничего, только установить код возврата (0 если найден, 1 если нет)

[EXAMPLE]:
which ls                 # путь к ls (/usr/bin/ls)
which -a python          # все пути, где находится python
which -s ls              # без вывода (проверить наличие)
```

#### last [display last logins] <a id="t_2.3.7"></a>
Выводит список последних успешных входов пользователей из файла `/var/log/wtmp`.

```bash
last [OPTION] [username...] [tty...]
 
[OPTION]:
-n N     — показать только последние N записей
-x       — показывать смену runlevel и завершения работы
-a       — показывать полное имя хоста в последнем поле
-i       — показывать IP-адреса вместо имён хостов

[EXAMPLE]:
last            # все записи
last -n 10      # последние 10
last -x         # с дополнительной информацией
last john       # только для пользователя john
```

#### id [print user and group identity] <a id="t_2.3.8"></a>
Команда id выводит информацию о текущем или указанном пользователе: UID (идентификатор пользователя), GID (основная группа) и список всех дополнительных групп.

```bash
id [OPTION]... [USER]

[OPTION]:
-u               — вывести только UID
-g               — вывести только GID
-G               — вывести все дополнительные GID
-n               — показывать имена вместо чисел (с -u, -g, -G)
-r               — показывать реальный ID вместо эффективного

[EXAMPLE]:
id               # информация о текущем пользователе
id -u            # только UID
id -G            # все группы (числовые)
id -Gn           # все группы (имена)
id john          # информация о пользователе john
```

#### hostname [host name] <a id="t_2.3.9"></a>
Команда hostname выводит или изменяет имя хоста системы.

```bash
hostname [OPTION]... [NEW_NAME]

[OPTION]:
-s, --short      — вывести короткое имя (до первой точки)
-i, --ip-address — вывести IP-адрес(а) хоста (зависит от разрешения)
-f, --fqdn       — вывести полное доменное имя (FQDN)
-I               — вывести все IP-адреса всех интерфейсов

[EXAMPLE]:
hostname                 # текущее имя хоста
hostname -s              # короткое имя
hostname -i              # IP-адрес
hostname -f              # полное доменное имя
hostname -I              # все IP-адреса
sudo hostname newname    # установить новое имя (требует прав)
```

#### date [print or set system date and time] <a id="t_2.3.10"></a>
Команда date выводит текущую дату и время в системе или устанавливает новую дату/время (требуются права суперпользователя).

```bash
date [OPTION]... [+FORMAT]
date [-u|--utc|--universal] [MMDDhhmm[[CC]YY][.ss]]

[OPTION]:
-d, --date=STRING    — вывести дату из указанной строки (не системную)
-s, --set=STRING     — установить системную дату из строки
-u, --utc            — показывать в UTC
-R, --rfc-2822       — вывод в формате RFC 2822
--rfc-3339=TIMESPEC  — вывод в формате RFC 3339 (TIMESPEC=date, seconds, ns)
+%Y-%m-%d %H:%M:%S   — задать произвольный формат вывода

[EXAMPLE]:
date                          # текущая дата и время
date +%Y-%m-%d                # только дата (2026-06-20)
date +%H:%M:%S                # только время (14:30:15)
date -u                       # UTC
date -d "yesterday"           # дата вчера
date -d "next Monday"         # дата следующего понедельника
date -s "2026-06-21 10:00:00" # установить время (требует sudo)
date --rfc-3339=seconds       # формат RFC 3339 с секундами
```

#### uptime [uptime] <a id="t_2.3.11"></a>
Команда uptime показывает текущее время, длительность работы системы, количество активных пользователей и среднюю нагрузку за 1, 5 и 15 минут.

```bash
uptime [OPTION]...

[OPTION]:
-p, --pretty     — выводить время работы в удобочитаемом формате (например, "up 2 days, 3 hours")
-s, --since      — показать дату и время запуска системы

[EXAMPLE]:
uptime           # стандартный вывод: время, аптайм, пользователи, нагрузка
uptime -p        # только время работы в красивом виде
uptime -s        # время запуска системы
```

#### echo [] <a id="t_2.3.12"></a>
Выводит строку текста, который был в неё передан

```bash
echo [SHORT-OPTION]... [STRING]...
echo LONG-OPTION

[OPTION]: 
-n - не выводить перевод строки
-e - включить поддержку вывода Escape последовательностей
-E - отключить интерпретацию Escape последовательностей

# Escape последовательности:
/c - удалить перевод строки;
/t - горизонтальная табуляция;
/v - вертикальная табуляция;
/b - удалить предыдущий символ;
/n - перевод строки;
/r - символ возврата каретки в начало строки.

[EXAMPLE]:
echo "Hello world"       # выведет "Hello world" с переводом строки
echo -n "No newline"     # выведет без перевода строки
echo -e "Line1\nLine2"   # выведет две строки
echo -e "Tab\tseparated" # с табуляцией
echo "Text with $PATH"   # выведет значение переменной PATH
echo *.mkv               # Вывести список файлов с расширением .mkv
```

### Как получить помощь по любой команде <a id="t_2.4"></a>
Список команд этого раздела, подробно они будут рассмотрены далее:

```bash
ls --help      — почти у всех команд есть флаг --help, краткая справка
man            — полное руководство (q — выход, / — поиск)
type ls        — что такое ls: команда, элиас или функция
apropos copy   — найти команды по ключевому слову
whatis         — краткое описание команды (из базы данных mandb).
info           — более структурированная, чем man документация для GNU-утилит
```

Интересная сторонняя утилита с краткими практические примерами **tldr** ( <https://github.com/tldr-pages/tldr> )

```bash
tldr ls        — выводит список из примеров использования
```

#### man [manual] <a id="t_2.4.1"></a>
Показать справку о команде. Навигация в man: ↑/↓ - листать, /слово - искать, n - перейти к следующему совпадению, q - выйти.

```bash
man <команда>
```

#### type [display command type] <a id="t_2.4.2"></a>
Команда `type` определяет и выводит информацию о том, как интерпретируется указанная команда в оболочке: является ли она встроенной, внешней, элиасом, функцией или ключевым словом.

```bash
type [OPTION]... COMMAND...

[OPTION]:
-t, --type       — вывести только тип команды (alias, keyword, function, builtin, file)
-p, --path       — вывести путь к исполняемому файлу, если это внешняя команда
-P, --all-paths  — вывести все пути в $PATH, соответствующие команде
-a, --all        — вывести все варианты (включая алиасы, функции и внешние)
-f, --force      — отключить поиск функций и алиасов (только внешние файлы)

[EXAMPLE]:
type ls                    # информация о команде ls
type -t ls                 # только тип (alias)
type -p ls                 # путь к ls (/usr/bin/ls)
type -P ls                 # все пути ls
type -a echo               # все варианты echo (встроенная, внешняя)
type cd                    # информация о встроенной команде cd
type -f cd                 # форсированный поиск внешнего файла (не найдёт, т.к. встроенная)
```

#### apropos [search manual page names and descriptions] <a id="t_2.4.3"></a>
Команда apropos выполняет поиск по именам и кратким описаниям справочных страниц (man pages), находя все команды, в описании которых встречается указанное ключевое слово. Полезна для поиска утилит, когда вы не помните точное имя.

```bash
apropos [OPTION]... KEYWORD...

[OPTION]:
-s, --section LIST — искать только в указанных разделах (например, -s 1,8)
-e, --exact        — искать точное совпадение с ключевым словом (без частичного совпадения)
-a, --and          — требовать наличия всех указанных ключевых слов (логическое И)
-w, --wildcard     — интерпретировать ключевые слова как шаблоны с wildcard (звёздочки)
-r, --regex        — интерпретировать ключевые слова как регулярные выражения

[EXAMPLE]:
apropos copy               # найти все команды, связанные с копированием
apropos -s 1,8 passwd      # искать passwd только в разделах 1 и 8
apropos -e ls              # точное совпадение с "ls"
apropos list               # команды, связанные со списком
apropos -a list directory  # команды, упоминающие и list, и directory
apropos -w "user*"         # все команды, начинающиеся с "user"
```

#### whatis [display one-line manual page descriptions] <a id="t_2.4.4"></a>
Команда whatis выводит краткое однострочное описание указанной команды из базы данных справочных страниц (man pages). Она полезна для быстрого получения информации о том, что делает команда, без необходимости открывать полную man-страницу.

```bash
whatis [OPTION]... COMMAND...

[OPTION]:
-w, --wildcard   — интерпретировать аргументы как шаблоны с wildcard (звёздочки и вопросительные знаки)
-r, --regex      — интерпретировать аргументы как регулярные выражения
-s, --section LIST — искать только в указанных разделах (например, -s 1,8)
-l, --long       — не обрезать вывод (показывать полные описания)

[EXAMPLE]:
whatis ls                # краткое описание ls
whatis -w "user*"        # все команды, начинающиеся с "user"
whatis -r "^ch.*"        # команды, начинающиеся с "ch"
whatis -s 1 passwd       # только из раздела 1
whatis -l bash           # полное описание без обрезания
```

#### info [read Info documents] <a id="t_2.4.5"></a>
Команда info используется для чтения документации в формате Info — альтернатива man, предоставляющая более структурированные и гипертекстовые руководства (особенно для программ GNU).

```bash
info [OPTION]... [COMMAND|SECTION]

[OPTION]:
-d, --directory=DIR — добавить DIR в список каталогов для поиска Info-файлов
-f, --file=FILE     — открыть указанный Info-файл (не искать по имени команды)
-n, --node=NODENAME — перейти к указанному узлу (node) внутри документа
-o, --output=FILE   — вывести содержимое в файл вместо интерактивного просмотра
-w, --where         — показать путь к Info-файлу для данной команды

[EXAMPLE]:
info ls                  # документация по ls в Info-формате
info coreutils           # документация по пакету coreutils
info -n "Date" date      # открыть узел "Date" в странице date
info -w ls               # показать путь к Info-файлу ls
info --output=ls.txt ls  # сохранить документацию ls в файл
```

#### file [determine file type] <a id="t_2.4.6"></a>
Команда file определяет тип указанного файла (например, текст, исполняемый, изображение, архив) путём анализа его содержимого, а не расширения имени.

```bash
file [OPTION]... [FILE]...

[OPTION]:
-b, --brief      — не выводить имя файла в начале строки (только тип)
-i, --mime       — выводить MIME-тип файла (например, text/plain)
-z, --uncompress — пытаться определить тип внутри сжатых файлов (gzip, bzip2 и т.д.)
-L, --dereference — следовать по символическим ссылкам (показывать тип целевого файла)
-s, --special-files — читать специальные файлы (например, блочные устройства) вместо вывода "special file"
-f, --files-from=FILE — читать список файлов для анализа из указанного файла

[EXAMPLE]:
file myfile.txt           # тип файла
file -b myfile.txt        # только тип (без имени)
file -i image.png         # MIME-тип (image/png)
file -z archive.tar.gz    # определить тип внутри сжатого архива
file -L /usr/bin/ls       # тип реального файла, на который ссылается симлинк
file -s /dev/sda          # тип содержимого блочного устройства (требует прав)
```
